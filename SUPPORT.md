# Struggling with GitHub?

Take these interactive courses to get up to speed!

## Beginner: GitHub as a Contributor

### Introduction to GitHub

This course will teach you how branches and pull requests work.

https://github.com/skills/introduction-to-github

### How do issues work?

The course above doesn't tell you about Issues. To fill this gap, we recommend this tutorial:

https://docs.github.com/en/issues/tracking-your-work-with-issues/learning-about-issues/quickstart

### How to use Markdown

This course will teach you how to perform **highlighting** and how to add `code sections` into text files.

https://github.com/skills/communicate-using-markdown

## Intermediate: GitHub as a Maintainer

### How do I handle pull requests?

This course will teach you how to review and accept a pull request.

https://github.com/skills/review-pull-requests

### Bringing it all together

Finally, this course teaches you the remaining knowledge you need to maintain a GitHub repository:

https://github.com/skills/introduction-to-repository-management
