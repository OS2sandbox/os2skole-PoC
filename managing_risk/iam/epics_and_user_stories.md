# Epics and User Stories related to IAM

### 1

**Who?** Student
**What?** I want to access a file that the teacher has shared with the class
**Why?** So that I can perform the expected task.

### 2

**Who?** Teacher
**What?** I want to share a document with the entire class
**Why?** So that I don't face the challenge of individually sharing with every student in the class

### 3

**Who?** Teacher
**What?** A new student joins the class. I want them to have the same document access as the other students in the class
**Why?** So that I can effectively teach the new student right from the get-go.

### 4

**Who?** Student
**What?** I want to only see those files in my file drive, that are relevant to my own class
**Why?** So that I don't get overwhelmed with irrelevant documents in my drive.

### 5

**Who?** Student
**What?** I want my teacher to know that I created the file required by an assignment.
**Why?** So that my teacher can see that it was me who did the work.

### 6

**Who?** Teacher
**What?** One or more students moved classes. I want them to have the same document access as the other students in the class.
**Why?** So I can effectively teach the new student(s) right from the get-go.

### 7

**Who?** Administrative Head Teacher ("Skoleleder")
**What?** I need all teachers and students to digitally reaffirm their identifies regularly before using any of the apps
**Why?** To be regulation compliant.
